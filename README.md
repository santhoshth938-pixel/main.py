# Campus Lost & Found Portal

A lightweight web application designed to help students report and claim lost items on campus.

## Features
- *Live Item Feed:* Dynamic listing of lost and found items.
- *Report Item:* Submit new items with custom secret questions.
- *Secret Verification:* Claim items securely by verifying secret answers without revealing contact details publicly.

## Tech Stack
- *Backend:* Python (Flask)
- *Database:* SQLite3
- *Frontend:* HTML5, Bootstrap 5, JavaScript (Fetch API)
